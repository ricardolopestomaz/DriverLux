# 🎭 User Stories

## EP1 - Catálogo de Veiculos

| User Story | Descrição |
|------------|-----------|
| **US01** | Como **cliente/visitante**, quero buscar veículos informando cidade, data/hora de retirada e devolução para ver apenas os disponíveis. |
| **US02** | Como **cliente/visitante**, quero ver na home as categorias de veículos com foto e preço para escolher rapidamente o tipo que preciso. |
| **US03** | Como **cliente/visitante**, quero ver os carros separados por grupos. |

---

## EP2 - Cadastro e Autenticação

| User Story | Descrição |
|------------|-----------|
| **US04** | Como **visitante**, quero criar conta com nome, e-mail, e senha para acessar o sistema. |
| **US05** | Como **cliente**, quero fazer login e permanecer autenticado para não precisar logar toda vez. |
| **US06** | Como **cliente**, quero editar meus dados cadastrais para manter minhas informações atualizadas. |

---

## EP3 - Fluxo de Reserva

| User Story | Descrição |
|------------|-----------|
| **US07** | Como **cliente**, quero ver o histórico de todas as minhas reservas para acompanhar. |
| **US08** | Como **cliente**, quero cancelar uma reserva futura. |
| **US09** | Como **cliente**, quero editar meus dados cadastrais para manter minhas informações atualizadas. |

---

## EP4 - Pagamento

| User Story | Descrição |
|------------|-----------|
| **US010** | Como **cliente**, quero pagar com cartão de crédito em até 12x para facilitar o pagamento. |
| **US012** | Como **sistema**, quero liberar a reserva somente após confirmação do pagamento para garantir a integridade. |

---

## EP5 - Painel Administrativo

| User Story | Descrição |
|------------|-----------|
| **US013** | Como **admin**, quero cadastrar veículos com fotos, categoria e valor/dia para disponibilizar no catálogo. |
| **US014** | Como **admin**, quero ver um dashboard simplificado com reservas do dia e veículos disponíveis. |
