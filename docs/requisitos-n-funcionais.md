# 📚 Requisitos Não Funcionais

| **Id**       | **RNF01** |
|--------------|----------|
| **Descição** | O sistema deve permitir que um usuário realize o fluxo de reserva em no máximo 5 etapas.

<br>

| **Id**       | **RNF02** |
|--------------|----------|
| **Descição** | O sistema deve carregar qualquer página em até 3 segundos. Busca de veículos deve retornar resultados em até 2 segundos.

<br>

| **Id**       | **RNF03** |
|--------------|----------|
| **Descição** | O sistema deve restringir o acesso ao painel administrativo apenas para usuários com perfil de administrador.

<br>

| **Id**       | **RNF04** |
|--------------|----------|
| **Descição** | O sistema deve possuir interface intuitiva, permitindo que novos usuários realizem uma reserva sem necessidade de treinamento.

<br>

| **Id**       | **RNF05** |
|--------------|----------|
| **Descição** | O sistema deve estar disponível 99% do tempo durante o período de uso.

<br>

| **Id**       | **RNF06** |
|--------------|----------|
| **Descição** | O sistema deve fornecer mensagens claras de erro e sucesso ao usuário.

<br>

| **Id**       | **RNF07** |
|--------------|----------|
| **Descição** | O sistema não deve permitir cadastro de dois veículos com a mesma placa. 
<br>

| **Id**       | **RNF08** |
|--------------|----------|
| **Descição** | O sistema não deve permitir cadastro de dois usuários com o mesmo e-mail.
<br>
